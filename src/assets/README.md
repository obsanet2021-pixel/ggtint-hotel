# Assets Folder

This folder contains images and other static assets for the GGT International Hotel website.

## Current Structure

Since this project uses inline SVGs and CSS gradients for most visual elements, this folder is currently minimal.

## Recommended Assets

To enhance the website, consider adding:

- **Room Images**: High-quality photos of:
  - Presidential Suite
  - Executive Deluxe Room
  - Superior Room
  - Family Suite

- **Dining Images**: Photos of:
  - Rooftop Restaurant
  - Ethiopian Heritage Restaurant
  - Lounge Bar

- **Event Spaces**: Photos of:
  - Grand Ballroom
  - Conference Center
  - Garden Terrace
  - Boardroom

- **Amenities**: Photos of:
  - Spa & Wellness Center
  - Pool Area
  - Fitness Center

- **Hotel Exterior**: Photos of:
  - Building facade
  - Lobby
  - Reception area

## Image Guidelines

- Use WebP format for better compression
- Recommended dimensions:
  - Room cards: 800x600px
  - Hero background: 1920x1080px
  - Gallery thumbnails: 600x450px
- Keep file sizes under 500KB each
- Use descriptive filenames (e.g., `presidential-suite-main.jpg`)
